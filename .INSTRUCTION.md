# Instructions for Deploying and Testing ToDo Application

## Applying Kubernetes Manifests

To deploy the ToDo application and related resources in your Kubernetes cluster, follow these steps:

1. **Apply the namespace manifest:**
   ```sh
   kubectl apply -f .infrastructure/namespace.yml
   ```

2. **Apply the BusyBox pod manifest:**
   ```sh
   kubectl apply -f .infrastructure/busybox.yml
   ```

3. **Apply the ToDo app pod manifest:**
   ```sh
   kubectl apply -f .infrastructure/todoapp-pod.yml
   ```

## Testing the ToDo Application

### Using Port-Forwarding
To access the ToDo application locally, use the following command to forward the container's port to your local machine:
   
```sh
kubectl port-forward pod/todoapp -n todoapp 8081:8080
```
   
Once the port-forwarding is active, open your browser and visit:
   
```
http://localhost:8081
```
   
### Testing with BusyBox (cURL)
You can test the application endpoints using the `busyboxplus:curl` pod:

1. **Get the name of the BusyBox pod:**
   ```sh
   kubectl get pods -n todoapp
   ```

2. **Run a cURL request from inside the BusyBox pod:**
   ```sh
   kubectl exec -n todoapp -it busybox -- curl -X GET http://todoapp:8000/
   ```
   
### Checking Readiness and Liveness Probes

#### Readiness Probe:
   ```sh
   kubectl exec -n todoapp -it busybox -- curl -X GET http://todoapp:8000/readiness/
   ```

#### Liveness Probe:
   ```sh
   kubectl exec -n todoapp -it busybox -- curl -X GET http://todoapp:8000/liveness/
   ```
   
If everything is configured correctly, you should receive HTTP 200 responses for both probes.

## Cleanup
To remove all deployed resources, run:
```sh
kubectl delete namespace todoapp
```
